## Overview
PENDEKAR - Pojok Education Career Scholarship is a digital platform in the form of a web-based application created using a front end framework called [Solid.js](https://www.solidjs.com/) with [Vite](https://vitejs.dev/), [TypeScript](https://www.typescriptlang.org/), and [Tailwind CSS](https://tailwindcss.com/) as a forum for students and alumni to obtain information and insights that can increase competitiveness in their careers.

The pages that can be accessed and have various features:
* Sign In
* Sign Up
* Landing Page
* Dashboard
  * Event
  * Scholarship
  * Jobs
  * Bookmark

## Prerequisite
* [Node.js 20.5.x or higher](https://nodejs.org/dist/v20.10.0/node-v20.10.0-x64.msi)
* [NPM 10.2.x or higher](https://www.npmjs.com/package/npm)
* [PNPM 8.11.x](https://pnpm.io/installation)

## Usage
```bash
pnpm install
```

## Available Scripts
In the project directory, you can run:

```bash
pnpm dev
```

Runs the app in the development mode.<br>
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

```bash
pnpm build
```

Builds the app for production to the `dist` folder.<br>
It correctly bundles Solid in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.<br>
Your app is ready to be deployed!
