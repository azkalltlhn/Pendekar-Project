# Backend PENDEKAR

## Project Name
Pendekar Project 

## Description
Website PENDEKAR (Pojok Education Career Scholarship) adalah sebuah platform yang menyediakan akses informasi terkait beasiswa, webinar, dan lowongan pekerjaan terbaru. Website ini bertujuan untuk membantu mahasiswa dan lulusan dalam mengembangkan diri, mengejar peluang pendidikan, serta membangun karier yang lebih baik. Selain itu, PENDEKAR juga berperan dalam mengurangi permasalahan pengangguran dan meningkatkan kualitas tenaga kerja di Indonesia dengan memberikan dukungan dan informasi yang relevan dalam menghadapi tantangan dunia kerja yang semakin kompleks.

Dari sisi teknis, backend website PENDEKAR dikembangkan menggunakan bahasa pemrograman Rust dan PostgreSQL sebagai database. Untuk mempermudah manajemen dan pengecekan database, digunakan DBeaver, sedangkan pengujian backend dengan database dilakukan melalui Postman. Selain itu, NGINX digunakan sebagai API gateway untuk memastikan performa dan keamanan dalam pengelolaan data serta komunikasi antara frontend dan backend.
